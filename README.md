OrangeHRM Manual Testing Project

Introduction
OrangeHRM is a web-based Human Resource Management application used to manage employee-related information and HR activities. This project focuses on manually testing the application's functionality to verify that it works as expected.

Project Objective
To test application features, validate expected results, and identify defects.

Testing Documents
- Test Plan
- Test Scenarios
- Test Cases
- Defect Report
- Software Requirements Specification (SRS)

Testing Type
- Manual Testing
- Functional Testing
- UI Testing

Tools Used
- OrangeHRM Web Application
- Microsoft Excel
- Microsoft Word

Conclusion
This project helped me understand test case preparation, test execution, defect reporting, and the manual testing process.
